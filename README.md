# Google Certified Device Checker (Next.js)

This project has been migrated to a unified Next.js application.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## API

The API is available at `/api/check`.

Example: `/api/check?device=Pixel`

## Legacy Code

The previous Python/Static implementation is archived in the `legacy/` directory.
